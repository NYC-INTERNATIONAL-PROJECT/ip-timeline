How this timeline stays up to date

The page reads your existing monthly tabs directly. Add a row to any month's tab — say, an Equip task in the Aug 10th week — and it appears here on the next load or "Refresh data". Nothing to redeploy.

Each monthly tab needs these four columns (header in row 1):

WeekProgramTaskStaff Responsible
Week 2EquipMid fundraise check (50% target)J. Smith
Aug 10InternshipHousing walkthroughOps team

Week is flexible: Week 2, 2, 2nd, last, a date like Aug 10 / 8/10, or phrases like Aug 10th week all land on the right week (weeks run Monday–Sunday, matching the sheet's week labels). Merged or blank Week/Program cells inherit from the row above, so grouped sheet layouts work as-is. New Program names automatically get their own swimlane and color.

Which tabs get read: every month from CONFIG.range.start to CONFIG.range.end, each expected as a tab named "Month Year" (e.g. March 2026). To extend the cycle, create the new tabs in the sheet and move end forward — that one date is the only yearly maintenance. Programs listed in IGNORED_PROGRAMS are hidden; PROGRAM_ALIASES merges name variants. The sheet must stay viewable by "Anyone with the link".

Views: Detailed shows one block per program per week. Executive is the general overview: the lifecycle ribbon (click a phase to open its checklist) plus each program's key milestones as labeled pills. Mark a task as a milestone by starting it with * (e.g. *Campaign Launch) or by putting any value in an optional Milestone column. The * never shows on the page. If nothing is marked yet, Executive shows one bar per program per active stretch with its task count instead. The phase names, positions, and checklists are the EXEC_PHASES block at the top of this file's script.

Setting up a fresh monthly tab? Copy month template puts the header row and two example rows on your clipboard — paste into cell A1.
