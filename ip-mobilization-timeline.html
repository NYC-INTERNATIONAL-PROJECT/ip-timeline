How this timeline stays up to date

Each time this file is opened, it tries to pull live data from the team Google Sheet. If the sheet can't be reached (offline, tab missing, or sharing turned off), it falls back to the snapshot embedded in this file — so the page always renders.

One-time sheet setup: in the Google Sheet, add a tab named Timeline, make sure link-sharing is set to “Anyone with the link can view”, and give the tab these column headers in row 1:

TrackEventStart DateEnd DatePhaseNotes
InternshipMid Fundraise Check2026-03-01Preparation3 months out — 50% raised target
EquipEquip Intensive Program2026-09-012026-09-30On FieldLeave End Date blank for single-point events

Dates are flexible: 2026-03-01, 3/1/2026, or Mar 2026 all work. An End Date turns the event into a colored duration bar; leaving it blank shows a point pill. New track names automatically get their own swimlane and color.
